# Universal Text Style Manager — Presets

A collection of ready-to-use presets for **Universal Text Style Manager**.

These presets allow you to quickly apply different visual styles to your Obsidian notes without writing CSS.

## How to use

1. Browse the available presets below.
2. Download the preset you want.
3. Open **Universal Text Style Manager** in Obsidian.
4. Use the **Import Preset** option to import the downloaded file.
5. Apply the preset to your notes and customize it to your preference.
